# Бот мониторинга тендеров на вентиляционное оборудование

Проверяет RSS-ленту РосТендера (ветка «Вентиляционное оборудование и материалы»,
охватывает 44-ФЗ, 223-ФЗ и коммерческие закупки) и присылает новые тендеры в Telegram.

Работает без сервера — через GitHub Actions по расписанию, бесплатно.

## Шаг 1. Создать Telegram-бота

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/newbot`, следуйте инструкциям, придумайте имя и username.
3. BotFather пришлёт **токен** вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.
   Сохраните его — это `TELEGRAM_BOT_TOKEN`.

## Шаг 2. Узнать chat_id, куда слать сообщения

Проще всего:
1. Напишите своему новому боту в Telegram любое сообщение (например «привет»).
2. Откройте в браузере:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
3. В ответе найдите `"chat":{"id":123456789,...}` — это и есть `TELEGRAM_CHAT_ID`.

Если хотите слать в канал — добавьте бота администратором канала,
и chat_id канала будет вида `-1001234567890`.

## Шаг 3. Выложить код на GitHub

1. Создайте новый **приватный** репозиторий на GitHub (приватный — чтобы токен
   и переписка не были видны посторонним, хотя сам токен в коде не хранится).
2. Загрузите туда все файлы из этой папки, сохранив структуру
   (включая `.github/workflows/monitor.yml`).

Через веб-интерфейс GitHub: New repository → Upload files → перетащить всё,
включая скрытую папку `.github` (если веб-интерфейс её не примет — используйте
`git` из командной строки или GitHub Desktop).

## Шаг 4. Указать токен и chat_id в секретах репозитория

В репозитории: **Settings → Secrets and variables → Actions → New repository secret**

Добавьте два секрета:
- `TELEGRAM_BOT_TOKEN` — токен из шага 1
- `TELEGRAM_CHAT_ID` — chat_id из шага 2

## Шаг 5. Первый запуск — «посев» без спама

Лента отдаёт последние ~30-50 тендеров. Если запустить бота как есть,
он разом пришлёт все текущие тендеры. Чтобы этого избежать:

1. Перейдите во вкладке **Actions** репозитория.
2. Выберите workflow **Tender Monitor** → **Run workflow**.
3. Поставьте галочку **seed_only** → **Run workflow**.

Это пометит все текущие тендеры как «уже виденные», ничего не отправив.
После этого бот будет присылать только по-настоящему новые тендеры.

## Шаг 6. Готово

Дальше бот сам проверяет ленту каждые 30 минут (можно поменять частоту
в `monitor.yml`, строка `cron`) и присылает новые тендеры в чат.

Проверить вручную в любой момент: Actions → Tender Monitor → Run workflow
(без галочки seed_only).

## Настройка фильтров

Откройте `main.py`, отредактируйте:
- `INCLUDE_KEYWORDS` — слова, при наличии которых тендер считается релевантным
- `EXCLUDE_KEYWORDS` — слова-исключения (шум из смежных категорий)
- `FEEDS` — список RSS-лент (можно добавить и другие категории РосТендера)

## Если понадобится больше источников или более частая проверка

GitHub Actions хорошо подходит для проверки раз в 15-30 минут. Если понадобится
мониторить чаще (например, раз в минуту) или добавить более сложную логику
(парсинг ЕИС, ЭТП Газпромбанка напрямую) — стоит перенести код на дешёвый VPS
(от ~150-300 ₽/мес, например Timeweb Cloud или Selectel) и запускать через cron.
Сам скрипт `main.py` для этого менять не придётся — только способ его запуска.
